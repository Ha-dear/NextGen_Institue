# 🚀 NextGen: Front-End Web Developer Internship (October-November) 2026
# 📖 Task Overview

This project is a clean, responsive, and semantically structured landing page for an online educational platform ("Creative Academy") built using **HTML5 and external CSS3 (`style.css`)**. The objective is to design an attractive educational homepage featuring a semantic navigation bar, an engaging hero section with background imagery, a responsive grid of popular courses with custom color-coded cards and badges, and smooth scroll behavior.

---

# ✨ Features

- **🎯 Semantic Navigation Header:** Clean structural layout featuring a custom brand logo, navigation links with active states, and smooth scrolling functionality.
- **🖼️ Engaging Hero Section:** Visually striking hero area featuring a high-resolution background image with a dark overlay, bold typography ("Learn Today, Build Tomorrow"), and a primary call-to-action button.
- **📊 Popular Courses Grid:** A responsive CSS Grid showcasing top courses (Web Development with a "NEW" badge, UI/UX Design, Data Science) utilizing unique color themes and interactive hover effects.
- **📝 Structured Footer & Utilities:** A clean dark footer matching the brand identity, alongside modern meta tags like auto-refresh and responsive viewport configurations.

---

# 🛠️ Technologies Used

- **HTML5:** Semantic elements (`<header>`, `<nav>`, `<section>`, `<footer>`) for a clean, accessible web structure, including meta configurations.
- **CSS3 (`style.css`):** Advanced styling using **Flexbox**, **CSS Grid**, media queries for responsiveness, smooth scrolling behaviors, and custom visual transitions.
