# 🚀 NextGen:Front-End Web Developer Internship (October-November) 2026

# 📖 Task Overview
This project is a pure HTML-based webpage that replicates a portfolio layout featuring an experience table, skills list, and contact form. It focuses on using semantic HTML structure and built-in HTML attributes for formatting without any external CSS.---

# ✨ Features
- **🎯 Semantic Header & About Me:** Clean structural layout featuring introductory headings and professional overview text.
- **🔗 Skills List:** A dedicated skills section highlighting core technologies (HTML, CSS, JavaScript, React.js, Angular) with external reference links.
- **📊 Professional Experience Table:** A comprehensive timeline table utilizing advanced table attributes (`rowspan`, `colspan`) and customized layout structures to display roles, company badges, key achievements, and dates.
- **📝 Interactive Contact Form:** A structured input section organized inside a `<fieldset>` and `<legend>` container using native table alignments for user details and action buttons.
---

# 🛠️ Technologies Used
- **HTML5:** Pure HTML structure, semantic tags (`<header>`, `<section>`, `<table>`, `<form>`, `<fieldset>`), and native attributes (`bgcolor`, `align`, `border`, `cellpadding`).
