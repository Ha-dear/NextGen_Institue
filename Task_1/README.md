# 🚀 NextGen: Front-End Web Developer Internship (October-November) 2026

# 📖 Task Overview

This project is a clean, responsive, and semantically structured portfolio webpage built using **HTML5 and Inline CSS (`style` attributes)**. The objective is to replicate a visual design layout featuring a skills list, a detailed experience timeline table with merged cells (`rowspan` / `colspan`), and a styled contact form without relying on external CSS files.

---

# ✨ Features

- **🎯 Semantic Header & About Me:** Clean structural layout featuring introductory headings and professional overview text styled with custom typography.
- **🔗 Skills List:** A dedicated skills section highlighting core technologies (HTML, CSS, JavaScript, React.js, Angular) with external reference links.
- **📊 Professional Experience Table:** A comprehensive timeline table utilizing advanced table attributes (`rowspan`, `colspan`) combined with inline CSS to display styled company badges, roles, key achievements, and dates.
- **📝 Interactive Contact Form:** A structured input section organized inside a `<fieldset>` and `<legend>` container using inline styling for clean alignments and custom call-to-action buttons.

---

# 🛠️ Technologies Used

- **HTML5:** Semantic elements (`<header>`, `<section>`, `<table>`, `<form>`, `<fieldset>`) for accessible web structure.
- **Inline CSS:** Applied lightweight `style` attributes for color schemes, spacing, font styling, and layout alignments.
